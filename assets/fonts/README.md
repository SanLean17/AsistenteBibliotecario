# Fuentes locales

Inter (texto e interfaz) y Lora (titulares y marca), distribuidas bajo SIL Open Font License 1.1. Se sirven desde este repositorio para compartir la misma tipografía en escritorio, Android y iOS, sin depender de Google Fonts en tiempo de ejecución.

Origen: https://github.com/google/fonts/tree/main/ofl/inter y https://github.com/google/fonts/tree/main/ofl/lora. Licencias incluidas junto a los archivos.
