# Si algo sale mal

1. No borres los datos ni reinstales el navegador.
2. Si la aplicación responde, exportá un respaldo y comprobá que se descargó.
3. Anotá sección, versión y operación. No incluyas nombres de estudiantes.
4. Volvé al inicio; si sigue igual, recargá una vez. Revisá si la operación ya quedó registrada antes de repetirla.
5. Continuá por una alternativa local segura o con el registro alternativo acordado con la escuela.
6. Restaurá solamente un archivo conocido y verificado. Conservá el archivo y el estado anterior. Ante préstamos activos, preferí comprobar el respaldo en un navegador separado.

| Problema | Qué podés hacer |
| --- | --- |
| Cámara bloqueada | Revisá el permiso del navegador. Usá fotografía, lector USB o escribí el código. No hace falta vaciar el catálogo. |
| Sin conexión | Si la aplicación quedó preparada, abrí la misma dirección y navegador. Usá catálogo, circulación e ingreso manual. Las fuentes externas no están disponibles. |
| Fuente bibliográfica no responde | Revisá si la otra fuente aportó datos; continuá manualmente y completá después. No vuelvas a crear la ficha si ya la guardaste. |
| Respaldo inválido | La importación se rechaza antes de escribir. Elegí otro archivo; no edites cantidades o identidades a mano para forzarlo. |
| No se pudo guardar | Mantené la ficha abierta y revisá el mensaje. Si falta espacio, conservá un respaldo fuera del equipo antes de liberar espacio. |
| Actualización pendiente | Terminá la tarea, descargá respaldo, cerrá otras pestañas de la biblioteca y abrí Configuración. Aplicá la actualización y comprobá el catálogo. |
| No abre después de una actualización | Conservá los datos del navegador. Si hay otra pestaña operativa, exportá desde allí. No borres el almacenamiento para «refrescar» la aplicación. Registrá el problema. |

El diagnóstico exportable no es un respaldo: no permite recuperar el catálogo. El respaldo no es sincronización: transferirlo no combina cambios de varios equipos.
